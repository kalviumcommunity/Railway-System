# Railway Catering Traceability System

## 🚂 Project Overview

**Problem Statement:**  
Indian railway catering services face food safety complaints due to untracked suppliers. What kind of digital traceability model could ensure hygiene and compliance?

## 💡 Proposed Solution

A **Digital Traceability Platform** for Indian Railway Catering Services that tracks food suppliers, ensures hygiene standards, and maintains compliance throughout the supply chain.

### Key Features:
- **Supplier Registration & Verification** - Onboard and verify all food suppliers with proper documentation
- **Real-time Tracking** - Track food items from source to serving
- **Hygiene Compliance Monitoring** - Digital checklists and audits for hygiene standards
- **QR Code Traceability** - Scan-based tracking for each food batch
- **Complaint Management** - Link complaints to specific suppliers and batches
- **Analytics Dashboard** - Insights on supplier performance and compliance metrics

## 🛠️ Tech Stack

**MERN Stack with TypeScript**
- **M** - MongoDB (Database)
- **E** - Express.js (Backend Framework)
- **R** - React.js (Frontend Library)
- **N** - Node.js (Runtime Environment)
- **TypeScript** - Type-safe JavaScript for better code quality
